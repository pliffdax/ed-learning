### Перевірка папки

Вивід ls:

```text
books.md
notes
personal.txt
reading-plan.md
```

Папка notes є у виводі ls, але git status її не показує. Результат перевірки після додавання файла всередину поки не записаний.

**Примітка:** спочатку оформлював документ без форматування, але потім зрозумів, що буде зручніше, якщо буду форматувати файл за правилами Markdown. Але перероблювати пункти до самостійної практики вже не доречно. На мій погляд, всі кейси розглянуті чітко і зрозуміло. Пізніше, коли Я перевірив вміст файлу, зрозумів, що не показав всі вправи крок за кроком, але досяг того самого результату, який очікувався.
